# Writing style rules (pavlin-skills)

Never use the long dash (em dash, "—") or the medium dash (en dash, "–") as punctuation anywhere: not in chat replies, not in generated copy, captions, scripts, documents, code comments, commit messages or file content. This applies in every language, including Czech.

Use only the short hyphen-minus ("-") where a dash is genuinely needed, and sparingly. Prefer a comma, a colon, parentheses or a new sentence instead. For ranges write "10-20" or "10 to 20".
